# Как добавить аппарат

Новый профиль добавляется JSON-файлом в `data/vehicles/`. После перезапуска проекта он появляется в меню автоматически.

## Минимальный формат

```json
{
  "id": "training_quad",
  "display_name": "Учебный квадрокоптер",
  "mass_kg": 0.8,
  "dimensions_m": { "length": 0.35, "width": 0.35, "height": 0.12 },
  "propeller_diameter_m": 0.13,
  "battery_wh": 60,
  "max_airspeed_m_s": 12,
  "max_wind_m_s": 6,
  "drag": { "cd": 1.0 }
}
```

Обязательны `id`, `display_name`, положительная `mass_kg`, размеры и положительная `max_airspeed_m_s`. `max_wind_m_s` используется для справочного ограничения. `battery_wh` и сведения о винте выводятся в профиле и участвуют в расчёте времени; это паспортные поля, если они известны, иначе укажите учебное допущение.

Поля должны описывать аппарат в СИ: масса в килограммах, размеры в метрах, скорость и ветер в метрах в секунду. Расчёт сопротивления калибруется по указанной максимальной скорости; это учебное приближение, а не измерение аэродинамики конкретного корпуса.

## Визуальная модель

`visual_scene` и `visual_span_m` необязательны. Если сцена GLB не указана, игра использует встроенное учебное представление. Масса всегда берётся из JSON и не вычисляется по размеру GLB. Рабочие модели проекта лежат в `data/models/flight/`.

## Проверка

Сохраните файл с расширением `.json`, перезапустите проект и выберите аппарат в стартовом меню. Если обязательное поле отсутствует или имеет неверный тип, профиль пропускается с сообщением в журнале.
