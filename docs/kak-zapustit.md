# Как запустить полёт у себя

Git для этого не нужен. Нужна бесплатная программа Godot.

## Скачать проект

1. Откройте ветку, не главную страницу: https://github.com/Melkor-code/infoteh/tree/arena/01a0da4d-infoteh
2. Зелёная кнопка Code → Download ZIP.
3. Распакуйте архив. Внутри должна быть папка, а в ней файл `project.godot`.

Если скачивали раньше, скачайте заново: старый архив без полёта.

## Поставить Godot

1. Откройте https://godotengine.org/download
2. Скачайте Godot 4.7.2 для Windows.
3. Берите обычную версию. Версия с подписью .NET не нужна.
4. Это архив, не установщик. Распакуйте и запустите `Godot_v4.7.2-stable_win64.exe`.

## Открыть и полететь

1. В окне Godot нажмите Import.
2. Укажите файл `project.godot` из распакованной папки.
3. Нажмите Import & Edit, затем кнопку Play сверху или клавишу F5.
4. Выберите «Геоскан Пионер Mini».
5. Оставьте включённым «Ветер 7 м/с с северо-запада».
6. Нажмите «Начать полёт», затем «Взлететь».

Mini в этом ветре не удерживается: так и задумано, его паспортная скорость ниже 7 м/с. Потом выйдите в меню и повторите на Phantom. Он тяжелее и по паспорту такой ветер ещё держит, если наклонить его против ветра.

Управление: W и S наклоняют вперёд и назад, A и D в стороны, Q и E поворачивают, Shift добавляет газ, Ctrl убавляет. Правая кнопка мыши крутит обзор. Клавиша C меняет камеру: сзади, из кабины, свободная.

Файл `.exe` для жюри из этого ещё не собран. Сначала нужно, чтобы полёт открылся у вас кнопкой Play. Сборку `.exe` сделаем отдельным шагом, когда полёт подтвердите.
