# Геоскан Пионер FPV — модель для Godot 4

Игровая 3D-интерпретация по фотографии image.png: четыре белых защитных кольца, карбоновая рама с отверстиями и стойками, нижние чёрные трёхлопастные пропеллеры, моторы с винтами, передняя FPV-камера, серебристый аккумулятор с ремнём «ГЕОСКАН», проводка, разъём и красная антенна.

Размеры и скрытые части приблизительные. Это не заводская CAD-модель. Некоторые мелкие детали стилизованы для игры.

## Быстрый запуск

1. Распакуйте архив.
2. В менеджере проектов Godot 4 нажмите «Импорт» и выберите project.godot.
3. Дождитесь импорта GLB, затем нажмите F5.

Демонстрационная сцена показывает модель с вращающимися винтами. Для осмотра остановленных винтов поставьте rotor_speed = 0 у экземпляра Drone в demo.tscn.

## Перенос в свою игру

Для статической модели достаточно geoscan_pioneer_fpv.glb: скопируйте файл в проект и перетащите в 3D-сцену. Материалы и текстура надписи встроены.

Для вращения винтов скопируйте fpv.tscn, propellers.gd и GLB. Добавьте fpv.tscn в сцену. Пути ресурсов рассчитаны на корень res://; при переносе в подпапку обновите пути в fpv.tscn.

Ось Y вверх, передняя камера смотрит по -Z, единицы — метры. Размах колец около 19,3 × 19,3 см; высота с антенной около 15 см. Центр модели расположен между четырьмя моторами. Propeller_0…Propeller_3 имеют локальные центры вращения на своих валах. Соседние винты вращаются в разные стороны.

Коллизия, физика полёта, управление и видеопоток FPV в комплект не входят. Можно поместить fpv.tscn под RigidBody3D и добавить простые CollisionShape3D по нуждам игры.

## Содержимое

- geoscan_pioneer_fpv.glb — самостоятельная модель glTF 2.0.
- fpv.tscn, propellers.gd — готовый экземпляр модели с вращением винтов.
- demo.tscn, demo.gd, project.godot — демонстрационный проект.
- preview.png — изображение созданной геометрии.
- build_fpv.py — исходный процедурный генератор (Python 3, NumPy, Pillow, SciPy).
- validation.json — результат проверки структуры модели.

Проверены контейнер GLB, буферы, диапазоны индексов, нормали, геометрия и центры вращения винтов. Сам редактор Godot в среде создания недоступен, поэтому запуск в нём не проверен.
