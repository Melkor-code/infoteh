# Как добавить аппарат

Новый профиль добавляется JSON-файлом в `data/vehicles/`. Имя файла — латиницей, без пробелов, расширение `.json`. Файл с именем на `_` в меню не попадает: так спрятан образец `_shablon.json`. После перезапуска проекта аппарат появляется сам. Код игры менять не нужно.

Это работает в открытой папке проекта. В уже собранный `.exe` новый файл снаружи не подхватится: паспорта упакованы внутрь программы.

## Как записывать число

Каждое число — объект с полем `value`, не голое число. Рядом пометка, откуда оно взято:

- `passport` — так написано у производителя, рядом ссылка;
- `assumption` — в паспорте этого нет, принято учебное правило;
- `missing` — значения нет, в `value` стоит `null`.

Нельзя ставить `passport` на число, которого нет в источнике. Phantom весит 1,388 кг, это не округляют до 1,5.

Без положительной `mass_kg.value` профиль молча пропускается. Пустой или сломанный JSON показывается в меню строкой «Ошибки чтения».

## Минимальный рабочий файл

```json
{
  "id": "training_quad",
  "display_name": "Учебный квадрокоптер",
  "mass_kg": {
    "value": 0.8,
    "origin": "assumption",
    "source": "",
    "comment": "Учебная масса. В паспорте её нет."
  },
  "dimensions_m": {
    "length": { "value": 0.35, "origin": "assumption", "source": "", "comment": "Метры." },
    "width": { "value": 0.35, "origin": "assumption", "source": "", "comment": "Метры. Входит в сопротивление." },
    "height": { "value": 0.12, "origin": "assumption", "source": "", "comment": "Метры. Входит в сопротивление." }
  },
  "max_airspeed_m_s": {
    "value": 12,
    "origin": "assumption",
    "source": "",
    "comment": "Метры в секунду. По этой скорости подгоняется сопротивление."
  }
}
```

Масса в килограммах, размеры в метрах, скорость в метрах в секунду. Ширина для расчёта берётся как большая сторона из ширины и длины. Если указана максимальная скорость, сопротивление подгоняется под неё. Это учебное приближение, не измерение корпуса.

Полезны, но не обязательны: `max_wind_m_s`, `flight_time_s`, `propeller_diameter_m`, батарея и `camera_fov_deg`. Их тоже пишите объектом с `value`. Если `flight_time_s` нет, для расхода батареи берётся запасные 600 секунд. Поля `drag` в расчёт не входят: коэффициент и заполнение площади заданы в коде общими для всех.

## Картинка

Необязательна. Без неё остаётся учебный корпус. Если она есть, добавьте две обычные строки, не объекты:

```json
"visual_scene": "res://data/models/flight/moy_apparat.glb",
"visual_span_m": 0.35
```

Файл `.glb` кладётся в `data/models/flight/`. В папке не должно быть своего `project.godot`, иначе Godot не увидит модель. Размах только масштабирует картинку. Масса всегда берётся из JSON. Винты с именами `Propeller_0`…`Propeller_3` крутятся сами, соседние в разные стороны.
