# Учебный симулятор БПЛА «АБДО»

Проект — учебный прототип по ТЗ «Инфотех». Он показывает полёт квадрокоптера на процедурном острове, работу ветра и осадков, смену времени суток, коллизии с рельефом и деревьями, телеметрию, мини-карту и экспорт отчёта.

Это не официальная программа Геоскана или DJI. Модели и характеристики в меню используются как учебные представления по открытым паспортным данным.

## Запуск

Требуется Godot 4.7 (обычная сборка, не .NET). Откройте папку проекта в Godot и запустите проект клавишей **F5**. На Windows можно запустить `START_SIMULATOR.cmd`: скрипт найдёт Godot в стандартных местах или предложит указать исполняемый файл.

## Аппараты и данные

Три рабочих GLB находятся в `data/models/flight/`. Их описания и параметры меню лежат в `data/vehicles/`. Четвёртый аппарат добавляется JSON-файлом по инструкции [data/vehicles/kak-dobavit-model.md](data/vehicles/kak-dobavit-model.md); код игры менять для этого не нужно.

## Управление

Подробное управление и настройки приведены в [docs/kak-zapustit.md](docs/kak-zapustit.md). Ресурсы острова и лицензии находятся в `assets/map/`.

## Ограничения прототипа

Физика использует воспроизводимую учебную модель с агрегированной тягой четырёх моторов и приближёнными коэффициентами сопротивления. Она предназначена для демонстрации решений ТЗ и не заменяет лётную модель реального аппарата.
